# OpenTEAM — OEDP-inspired static site

This repository is a static HTML/CSS/JS site designed for **GitLab Pages or GitHub Pages**.
It uses an OEDP-inspired layout (sticky header + left drawer menu) and includes image-backed tiles/cards.

## Files
- `index.html` – homepage content
- `styles.css` – styling
- `script.js` – menu drawer behavior + accessibility
- `assets/` – logo + background images
- `.gitlab-ci.yml` – GitLab Pages deployment
- `.github/workflows/pages.yml` – GitHub Pages deployment

## Attribution
Design is inspired by Open Environmental Data Project (openenvironmentaldata.org).
